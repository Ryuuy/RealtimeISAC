# 2026-10-10 金属板刀口（knife-edge）遮挡实验

NTG-2501（JRC 25 GHz）链路，Master 192.168.1.201 ↔ Slave 192.168.1.101，**距离 D = 6 m**。金属板在**第 3 m（中点）**，
缓慢横向移出 LOS，观察链路何时断开/恢复、断开时的 USRP 与 NTG 特征。

> 这份数据**很重要**：`raw/` 里是**完整未裁剪的原始文件**（含 18:19:30 之后撤离的部分），只读不改，校验和见下。
> 图和分析只用到 18:19:30 之前（撤离部分按要求不画、不分析）。

## 2. Fresnel zone（菲涅尔区）宽度

载波取 **25 GHz** 标称（JRC 25 GHz 小电力データ通信装置，**具体信道中心频率未记录**，±1 GHz 只影响 r1 约 ±2%）。
波长 λ = c / f = **11.99 mm**。注意：USRP 的 1.89 GHz 只是毫米波前端下变频后的**中频**，不是真实载波，
所以**感知用的就是这条 25 GHz 信号本身，感知与链路的菲涅尔区是同一个**。

第 n 菲涅尔区半径（距发射端 d1、距接收端 d2，D = d1 + d2 = 6 m）：

    r_n = sqrt( n · λ · d1 · d2 / D )

| 板子位置 d1 / d2 | **第一菲涅尔区半径 r1** | **直径 2·r1（宽度）** | 0.6·r1（常用无遮挡净空） |
|---|---:|---:|---:|
| 0.5 m / 5.5 m | 7.4 cm | 14.8 cm | 4.4 cm |
| 1.0 m / 5.0 m | 10.0 cm | 20.0 cm | 6.0 cm |
| 1.5 m / 4.5 m | 11.6 cm | 23.2 cm | 7.0 cm |
| 2.0 m / 4.0 m | 12.6 cm | 25.3 cm | 7.6 cm |
| **3.0 m / 3.0 m（本实验板子位置）** | **13.4 cm** | **26.8 cm** | **8.0 cm** |

本实验在中点：**r1 = 13.4 cm（第一菲涅尔区宽度 = 26.8 cm）**；第二、第三区半径 r2 = 19.0 cm、r3 = 23.2 cm。
（24 GHz → r1 13.7 cm；26 GHz → r1 13.2 cm。）

刀口衍射参数 ν = h · sqrt(2D / (λ d1 d2)) = **h · 10.54**（h 为板边越过 LOS 的距离，单位 m；板边在 LOS 之后为 h > 0）。
损耗近似 J(ν) = 6.9 + 20 log10( sqrt((ν−0.1)² + 1) + ν − 0.1 ) dB（ν > −0.78）：
ν = 0 → 6.0 dB；ν = 1（h = 9.5 cm）→ 13.9 dB；ν = 1.7（h = 16.1 cm）→ 17.8 dB；ν = 2（h = 19.0 cm）→ 19.0 dB。

## 4. 定义

- **链路在线 / 断开**：以 USRP **ch0（reference）** 为真值：> −30 dBFS = 在线（约 −6 dBFS），否则断开（约 −52 dBFS）。
  比 NTG HTTP 更可靠——断开时 Master 的 HTTP 经常读不到。`transitions.csv` 是 ch0 的上/下沿（共 35 个，窗口内）。
- **loss vs clear**：以 30–40 cm（链路 100% 在线、完全无遮挡）的 Slave Rx 中位数 **−50.25 dBm** 为基准，Rx 比它低多少 dB。
- Slave Rx/CNR 是**下行**（Master→Slave，192.168.1.201 → 192.168.1.101）。

## 6. 观察（以数据为准；标注"推断"的是推断）

1. **0–16 cm 是不稳定区**：多数格链路以断开为主，偶尔恢复几秒到十几秒又断（见 `transitions.csv`；6 cm 是例外，约 78% 在线，18:10:36 起连续在线 ≈ 24 s）。0、10 cm 两格 NTG 完全读不到 Master。
2. **18 cm 起大部分时间在线**（18–22 cm：79–100%）；**24、26 cm 各出现一次约 10 s 的断开**（18:15:08–18:15:18、18:15:31–18:15:41，在线 67%；后一次距该步开始仅 1 s），
   此时 Rx ≈ −54 ~ −55 dBm（loss 仅 4–5 dB），远高于 −67 dBm 的断开门限，**不是单纯的功率不足**——可能与该位置附近的人/板子移动（每次移动的实际时刻未打点）或一次短暂深衰落有关，**需要复测核实**；
   28 cm 起 100% 在线，Rx ≈ −50 dBm、CNR ≈ 22–27 dB（无遮挡）。
3. **断开门限**：在 0–16 cm 的不稳定区，Rx ≈ −67 ~ −68 dBm、CNR ≈ 11–12 dB，对应 loss ≈ 17–18 dB（链路余量 ≈ 17 dB）。
4. **Rx 从 −58 dBm 爬回 −50 dBm 的过渡发生在偏移 18 → 30 cm**，宽度约 12 cm，与第一菲涅尔半径 13.4 cm 同量级——符合刀口衍射的过渡尺度。
5. **（推断）板边擦到 LOS 的偏移 ≈ 21 cm**：把每格 loss 反解成 ν、再反解 h（`analyze_steps.py` 打印，12–26 cm 的 8 格中位数 21 cm，范围 18–23 cm），
   即板边在偏移 ≈ 21 cm 处与 LOS 重合（loss ≈ 6 dB）。2–8 cm 因链路已在断开门限附近、Rx 读数被截断，不用于该推断。
6. **慢速遮挡下多普勒几乎不触发**：各格 Doppler verdict 占比 0–8%（多数 ≤ 5%），而链路已断开/反复断开。
   即**缓慢遮挡对多普勒不可见，功率/CNR 才可见**。
7. 断开瞬间 ch0 会先掉到约 −58 dBFS（接近监测下限 −60）再稳在约 −52 dBFS；断开期间 ch0 与 ch1 电平接近（差 0–4 dB）且起伏相关系数 0.8–0.99（10-09 会话 163214 的观察，本会话未单独验证），
   更像两路收到同一个很弱的信号（NTG 建链期间的发射或共模杂散），**未用 50 Ω 负载验证过空载底噪**。

## 7. 已知局限 / 注意

- 位置序列来自操作者口述的时间表，**没有回车打点**（`n_markers = 0`），每次移动的实际时刻可能与整 30 s 有数秒偏差；移动瞬间人影响 ch1 与多普勒。
- 板子尺寸、板边与 LOS 的实际零点未实测；上面的"板边偏移 21 cm"是反推，需用实测板宽核对。
- 浏览器快照导出时 **ISAC interface = ON**（`meta.isacInterfaceEnabledAtExport = true`）：视频码率/buffer 受 ISAC 影响，分析链路物理时不受影响。
- 菲涅尔区按 25 GHz 标称算；刀口公式为单刀口近似，未计金属板的反射/多径（Rx 随位置会有几 dB 纹波）。
- 同一会话的 npz/CSV 记录到 18:32（超出本实验窗口），包含 18:19:30 之后的撤离与后续数据，保留在 `raw/` 中未裁剪。
